WEBSITE DUA PUTRI BIMA BERSAUDARA
=================================

CARA MEMBUKA:
1. Ekstrak file ZIP ini.
2. Buka folder website_dpbb.
3. Klik dua kali file index.html.
4. Website akan terbuka di browser (Chrome/Edge).

JIKA MENGGUNAKAN XAMPP:
1. Salin folder website_dpbb ke C:\xampp\htdocs\
2. Jalankan Apache dari XAMPP Control Panel.
3. Buka browser dan ketik: http://localhost/website_dpbb/

FILE:
- index.html       Halaman utama website
- style.css        Tampilan dan desain website
- script.js        Menu navigasi dan tahun otomatis
- assets/logo-dpbb.jpeg  Logo usaha
